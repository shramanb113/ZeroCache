# Getting Started with Aurora Cloud Storage

Aurora Cloud Storage is an object storage service for backing up and sharing files. To begin, create a bucket from the dashboard, then upload files via the web UI, the CLI (`aurora cp ./file.txt s3://my-bucket/`), or the REST API. New accounts start on the Free tier, which includes 5GB of storage and 10GB of monthly egress. Files are encrypted at rest by default; no configuration is required to enable this.
